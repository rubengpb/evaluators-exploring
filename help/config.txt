The config command is the tool to check the config.

The config of the repl is defined by:

    Params:
      eval        -> evaluator: the language, substituion manager, style and strategy
      env         -> env: the list of <id> with its related terms
      church_num  -> if the result has the form of number church encoding, print it
      church_list -> if the result has the form of list church encoding, print it
      display     -> before print the result, print the expanded term to evaluate
      simulator   -> a game to simulate some strategies inside others changing the
                     initial term to evaluate

Each of this params can be consulted:


    Commands:
      :config eval        -> All the options of the evaluators
      :config eval <opt>  -> The selected <opt> of the evaluator

      :<config>? env      -> See more details with :h env
      :<config>? env <id> -> See more details with :h env
      :<config>? expEnv   -> See more details with :h env

      :config church      -> Church display options, see more at :h church
      :config church <opt>-> Current church <opt>, see more at :h church

      :config display
      :config simulator   -> Simulator config
      :config sim         -> Simulator config
