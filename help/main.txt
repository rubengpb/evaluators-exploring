Simple λ-REPL: type lambda-terms, assign lambda-terms and use them in expressions.

Type :q to exit.

     Commands:
       :load <file>
       :t <id>
       :config <param>
       :set <param> <opt>
       :env <opt>

More info about each command with       :h <command>
More info about evals with              :h evals
More info about "syntax sugar"
for numbers and list with               :h church
More info about "short names" in
options and evals-names with            :h names
More info abour some prebuilt-in
files with terms definitions            :h prebuilt

     Evaluation of terms:
       Type <id> = <term> to assign an id to a term.
       Type <term> to evaluate a term.
       Type :t <id> to evaluate the type of a term.
