The REPL env store some predefined terms. You can config it:

    To inspect the env:
      :env                  -> display all the definitions using the exact string
                               with it was defined
      :env <id>             -> search the <id> in the env and show (if exists)
                               the definition
      :expEnv | expandedEnv -> display all the definitions, expanding also the
                               <id>s inside it
      :envEnv <id>             -> search the <id> in the env and show it expanded

How use the env correctly? When you defined a term it is inmediately expanded.
This means that new defined terms cannot be change previous terms.
